# taste_of_africa_website_project
A website about African food, built with HTML, CSS and JavaScript.

## Pages
Home, Recipes, West Africa, East Africa, North Africa, About, Contact, and four recipe pages (Jollof Rice, Injera, Isombe, Lamb Tagine).

## Features
- Recipe filter by region
- Favorites saved in localStorage
- Servings box that changes the amount of ingredients
- Dark and light mode
- Contact form with validation

## How to run it
run your index.html using live server
